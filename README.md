# Life Expectancy and GDP Analysis

## Overview
This project explores the relationship between **life expectancy at birth** and **GDP** across different countries over time. The goal is to understand how health outcomes and economic performance may be connected, and how both variables change from year to year.

The analysis uses country-level data with the following columns:
- `country`
- `year`
- `life expectancy at birth (years)`
- `GDP`

## Project Goals
This project aims to:
- examine how life expectancy changes over time
- compare GDP trends across countries
- investigate the relationship between GDP and life expectancy
- identify patterns, similarities, and differences between countries

## Objectives
- load and inspect the dataset
- clean the data and check for missing values
- summarize the data using descriptive statistics
- visualize trends in life expectancy and GDP
- analyze the relationship between GDP and life expectancy
- apply statistical methods such as correlation, hypothesis testing, and linear regression
- draw conclusions from the findings

## Research Questions
Some of the main questions this project answers are:
- How has life expectancy changed over time in each country?
- How has GDP changed over time in each country?
- Is there a relationship between GDP and life expectancy?
- Do countries with higher GDP tend to have higher life expectancy?
- Which countries show the highest or lowest life expectancy?

## Hypothesis
**Null Hypothesis (H0):** There is no significant relationship between GDP and life expectancy.

**Alternative Hypothesis (H1):** There is a significant relationship between GDP and life expectancy.

## Methods Used
This project is an **observational data analysis**, not a controlled experiment. The following methods are used:
- descriptive statistics
- exploratory data analysis (EDA)
- data visualization
- correlation analysis
- hypothesis testing
- linear regression

## Tools and Libraries
This project was completed in **Jupyter Notebook** using Python libraries such as:
- `pandas`
- `matplotlib`
- `seaborn`
- `scipy`
- `scikit-learn`

## Visualizations
The project includes visualizations such as:
- line charts for life expectancy over time
- line charts for GDP over time
- scatter plots of GDP vs life expectancy
- bar charts comparing country averages
- regression plots showing trends between variables

## Key Insights
Some expected insights from this analysis include:
- life expectancy generally improves over time in many countries
- GDP changes at different rates across countries
- higher GDP is often associated with higher life expectancy
- GDP alone may not explain all differences in life expectancy between countries
